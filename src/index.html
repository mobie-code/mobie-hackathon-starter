mobie Hackathon Starter

Melde dich einmal mit deinem Staging-Testfahrgast an. Der Server erneuert den Access Token automatisch.

Ein Server-Prozess gehört zu einem Testfahrgast. Alle Telefonanrufe über diesen Starter verwenden dessen Konto.



Nach dem Login: Team-Schlüssel erneut eingeben und die API-Verbindung prüfen. Der Schlüssel wird nicht im Browser gespeichert.

Die Dokumentation und Beispielaufrufe findest du in der README und unter docs/api.md in deinem Repository.

Tokens verbleiben im Arbeitsspeicher. Nach einem Server-Neustart ist ein neuer Login erforderlich.
